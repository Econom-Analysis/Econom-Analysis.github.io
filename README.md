# 计量经济分析

项目主页： https://econom-analysis.github.io

## 项目简介

这是一个围绕《计量经济分析》教材搭建的静态网站仓库，用于集中展示教材介绍、课程配套资料和延伸学习资源。网站内容面向经济、金融、管理等相关专业的学习者，也适合作为计量经济学入门与教学辅助材料使用。

当前站点以 GitHub Pages 形式发布，仓库中的 `index.html` 是网站首页入口，相关 PDF 课件和附录资料直接随仓库存放并对外提供访问。

## 网站内容

项目当前主要包含以下几类内容：

- **教材简介**：介绍《计量经济分析》的写作定位、适用对象和主要特色。
- **教材附录**：提供 Stata 入门、R 入门和矩阵代数等 PDF 资料。
- **课程课件**：提供若干章节的 Slides 文件，方便教学展示和自学复习。
- **外部资源**：整理因果推断、数据科学与数据分析语言学习链接。

## 适用场景

这个项目比较适合以下用途：

- 作为教材配套网站在线访问；
- 用作课程主页或教学资源汇总页；
- 供学生下载课件、附录和参考资料；
- 作为一个轻量级静态学术网站示例进行维护或扩展。

## 本地查看方式

由于这是一个静态网站仓库，通常不需要复杂的构建流程。你可以直接通过以下任意方式查看：

1. 直接在浏览器中打开 `index.html`；
2. 使用任意静态文件服务器在仓库根目录启动本地预览；
3. 推送到 GitHub Pages 后通过线上地址访问。

例如，在仓库根目录运行：

```bash
python -m http.server 8000
```

随后访问 <http://localhost:8000> 即可本地预览。

## 维护说明

- 如果新增课件或附录，建议保持目录结构清晰，并在首页中同步添加入口链接；
- 如果替换已有 PDF 资源，建议同时更新文件名或更新说明，避免缓存影响访问；
- 如需扩展更多页面，建议继续沿用静态页面和资源直链的方式，保持仓库简单易维护。
